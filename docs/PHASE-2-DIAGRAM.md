## State Flow

```
┌────────────────────────────────────────────────────────────────────────────┐
│                    ~/.local/share/oqvian/state/                            │
│                                                                             │
│  www_example_com.json          ← chain auto-updates phase & discovered     │
│  chains/www_example_com_...json ← chain execution history                  │
│  pivots.json                   ← active pivot tunnels                      │
│  learning.json                 ← adapt technique results                   │
│  loot/                         ← collected flags, creds, configs           │
└────────────────────────────────────────────────────────────────────────────┘
```

## Adaptive Learning Loop

```
┌────────────────────────────────────────────────────────────────────────────┐
│  Technique tried → Result (success/failed) → Reason (WAF, timeout, etc.)   │
│       │                                              │                     │
│       │                                              ▼                     │
│       │                                      adapt() records               │
│       │                                              │                     │
│       │                                              ▼                     │
│       │                                      Auto-recommendation           │
│       │                                              │                     │
│       │                                              ▼                     │
│       │                                      backtrack() suggests           │
│       │                                      alternatives                  │
│       │                                              │                     │
│       └──────────────────────────────────────────────┘
│                              │
│                              ▼
│                      Try next technique
│                              │
│                              ▼
│                      (loop until success or exhaustion)
└────────────────────────────────────────────────────────────────────────────┘
```
